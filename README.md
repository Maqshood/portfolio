## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/Maqshood/portfolio.git
cd portfolio
```

Install dependencies:

```bash
npm install
```

---

## ⚙️ Environment Variables

If you are using EmailJS for the contact form, create a `.env.local` file in the project root:

```env
EMAILJS_SERVICE_ID=your_service_id
EMAILJS_TEMPLATE_ID=your_template_id
EMAILJS_PUBLIC_KEY=your_public_key
```

---

## 💻 Run Locally

Start the development server:

```bash
npm run dev
```

Visit:

```
http://localhost:3000
```

---

## 🏗️ Production Build

Build the application:

```bash
npm run build
```

Start the production server:

```bash
npm start
```
